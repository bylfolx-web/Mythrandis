# Mythrandis — Creative Writing Workflow

This is a creative writing project using Claude Code. All writing follows the instructions in `CLAUDE.md` and is written in Byl's Voice.

## How This Works

- World information is split into separate files by topic for token efficiency. Only read what the scene needs.
- Character profiles contain personality, speech samples, internal thoughts, and body language organized by emotion. These are reference — use them to stay in voice, not to copy verbatim.

## Rules

- Always read `CLAUDE.md` before any creative writing.
- Always read `Byls_Voice.xml` before any creative writing.
- Only read world files that are directly relevant to the current scene. Do not load everything.
